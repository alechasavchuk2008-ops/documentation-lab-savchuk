# 🔌 Технічна документація API VotePulse

Нижче наведено базові ендпоінти REST API для взаємодії з платформою опитувань.

### 1. Отримати список активних опитувань
* **Endpoint:** `GET /api/v1/polls`
* **Опис:** Повертає список публічних опитувань.
* **Приклад відповіді (JSON):**
```json
{
  "status": "success",
  "code": 200,
  "data": [
    {
      "poll_id": 42,
      "title": "Вибір дати проведення курсової",
      "is_anonymous": true,
      "total_votes": 18
    }
  ]
}


2. Відправити голос
Endpoint: POST /api/v1/polls/{poll_id}/vote

Приклад запиту (JSON):
{
  "option_id": 3
}

🛠 Коди помилок
200 OK — Голос успішно враховано / дані отримано.

400 Bad Request — Некоректні дані або ви вже проголосували.

403 Forbidden — Доступ до опитування обмежений.

404 Not Found — Опитування з таким ID не знайдено.
