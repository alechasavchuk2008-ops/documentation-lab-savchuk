# 🗳 VotePulse — Платформа для голосування та опитувань

## 📌 Про систему
**VotePulse** — це сучасна веб-платформа для швидкого створення, проведення та аналізу онлайн-голосувань і опитувань. Вона вирішує проблему збору зворотного зв'язку в навчальних закладах, компаніях та спільнотах, забезпечуючи чесність, анонімність та прозорість підрахунку голосів.

## ✨ Основні функції
* Створення відкритих та закритих (за посиланням/кодом) опитувань.
* Підтримка різних типів питань: одиночний вибір, множинний вибір, текстова відповідь, шкала оцінювання.
* Візуалізація результатів у реальному часі за допомогою діаграм та графіків.
* Захист від повторного голосування (за IP, cookie або авторизацією).

## 👥 Цільова аудиторія
* Студенти та викладачі (для опитувань, голосувань у групах, виборів старости).
* Команди та організації (для збору фідбеку, прийняття колегіальних рішень).
* Організатори івентів (для швидкого збору думок аудиторії).
