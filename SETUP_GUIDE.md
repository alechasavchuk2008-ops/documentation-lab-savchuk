# ⚙️ Інструкція з запуску та налаштування

## 🛠 Необхідні інструменти
* Будь-який сучасний веб-браузер (Google Chrome, Mozilla Firefox, Safari, Edge).
* Підключення до мережі Інтернет.
* Створений обліковий запис у системі для створення власних опитувань (для участі в голосуванні реєстрація може бути необов'язковою).

## 📥 Покроковий запуск (Local/Web)
1. Відкрийте браузер та перейдіть за адресою сервісу (`https://votepulse.example.com`).
2. Для запуску локальної копії проєкту:
   * Клонуйте репозиторій: `git clone https://github.com/user/vote-pulse.git`
   * Відкрийте файл `index.html` у браузері або запустіть локальний сервер.

## ✅ Перевірка роботи
* Головна сторінка відкривається без помилок 404/500.
* Створивши тестове опитування, перевірте, чи генерується унікальне посилання для голосування.
